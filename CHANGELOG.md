# Changelog

All notable changes are documented here. The format follows Keep a Changelog
and the project uses semantic versioning.

## [1.0.0] - 2026-09-20

### Added

- Persian-first React workspace with light and dark themes
- PDF, DOCX, TXT, and Markdown ingestion
- sentence-aware chunking with overlap
- multilingual Ollama embeddings and Qdrant vector search
- SQLite FTS5 lexical search with Persian normalization
- weighted Reciprocal Rank Fusion and document diversity cap
- streamed Ollama and OpenAI-compatible generation
- inspectable citations and persisted conversation history
- deterministic demo mode and offline backend test suite
- Docker Compose, CI, sample documents, and retrieval evaluation script
