# متن آماده برای LinkedIn

چند وقت بود می‌خواستم یک پروژه RAG بسازم که فقط «چت با PDF» نباشد.

نتیجه شد «دانشیار»؛ یک دستیار اسناد فارسی که جواب را همراه با منبع، شماره صفحه
و همان تکه متنی که برای پاسخ استفاده شده نشان می‌دهد.

در این پروژه:

- Backend را با FastAPI نوشتم.
- برای جست‌وجوی معنایی از Qdrant و Embedding چندزبانه استفاده کردم.
- جست‌وجوی کلیدواژه‌ای FTS5 را هم اضافه کردم تا نام‌ها، کدها و عبارت‌های دقیق
  گم نشوند.
- نتایج دو مسیر با Weighted RRF ترکیب می‌شوند.
- پاسخ مدل محلی Ollama به‌صورت زنده در رابط React نمایش داده می‌شود.
- برای آپلود، حذف، تشخیص فایل تکراری، تاریخچه گفتگو و استنادها تست نوشته‌ام.
- کل پروژه با Docker Compose قابل اجراست.

یکی از تصمیم‌های مهمم این بود که هسته بازیابی را پشت LangChain پنهان نکنم.
می‌خواستم دقیقاً بدانم سند چطور قطعه‌بندی می‌شود، رتبه‌ها چطور ترکیب می‌شوند و
هر منبع چطور به پاسخ نهایی وصل می‌شود.

نسخه اول محدودیت‌های مشخصی هم دارد: PDF اسکن‌شده فعلاً به OCR قبلی نیاز دارد و
برای استفاده چندکاربره باید احراز هویت و صف پردازش پایدار اضافه شود.

کد، معماری، داده نمونه و روش اجرای پروژه را در GitHub گذاشته‌ام:

https://github.com/Abouzarsh/daaneshyar-rag

اگر تجربه‌ای درباره RAG فارسی، Hybrid Search یا ارزیابی کیفیت بازیابی دارید،
خوشحال می‌شوم نظرتان را بدانم.
